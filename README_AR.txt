عالم الطفل - Kids World | النسخة المعدلة

محتويات التعديل:
- إصلاح GitHub Actions ليبني مشروع Android الموجود مباشرة دون اشتراط ملف ZIP خارجي.
- تشغيل البناء تلقائياً عند الدفع إلى main أو master، أو يدوياً من Actions.
- إضافة ركن حوارات ريتال وكنان بالعربية والإنجليزية مع صور رمزية ونطق صوتي عند الضغط.
- إضافة حوارات للحيوانات والأشياء مع انتقال بين الأمثلة وسؤال بسيط.

طريقة الاستخدام:
1. فك ضغط الملف.
2. ارفع محتويات مجلد kidsworld_fixed إلى جذر مستودع GitHub، مع إظهار المجلدات المخفية مثل .github.
3. افتح تبويب Actions وشغّل Build Kids World APK، أو ادفع التعديلات إلى main.
4. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل ملف APK من Artifacts.

ملاحظات مهمة:
- الصوت الحالي يستخدم محرك تحويل النص إلى كلام الموجود على جهاز Android؛ قد تختلف الأصوات حسب الجهاز واللغات المثبتة. ليست ملفات أصوات أطفال مسجلة.
- هذه نسخة Debug للاختبار وليست إصدار متجر Google Play.
- احتفظ بمفتاح توقيع ثابت قبل إعداد إصدار النشر.
